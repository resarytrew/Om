# Виртуальная лаборатория: Закон Ома

Интерактивный учебный эксперимент по закону Ома в формате одного статического веб-приложения.

## Что уже работает

- изменение напряжения `U` от 0 до 12 В;
- изменение сопротивления `R` от 1 до 10 Ом;
- автоматический расчёт силы тока по закону `I = U / R`;
- интерактивный амперметр: стрелка и цифровое табло меняются вместе с током;
- визуальная анимация условного движения зарядов в цепи;
- динамический график зависимости `I(U)`;
- четыре учебных режима: **Наблюдай → Изменяй → Предскажи → Объясни**;
- проверка прогноза об удвоении сопротивления;
- адаптивный интерфейс без внешних библиотек и без сборщика.

## Запуск

Откройте `index.html` в браузере. Для публикации можно включить GitHub Pages для ветки `main` после слияния pull request.

> Движущиеся световые точки используются как условная визуализация величины тока и не изображают реальную дрейфовую скорость электронов в масштабе.
